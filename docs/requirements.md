# 絶縁USBハブ 要件定義書

- 作成: 2026-10-28
- 状態: ドラフト(要件詰め中)

## 1. 目的と背景

下流側でショートした機器や電位差のある機器をつないでも、PC側のUSBポートに影響を与えない絶縁USBハブを自作する。

- **課題**: ショート状態の機器を接続したときに、PC側のポート保護(ヒューズ・eFuse)が動作したり、最悪の場合PCが損傷したりするのを避けたい
- **現状**: 市販の絶縁USBハブ(産業用)は高価で、USB-C端子の製品も少ない
- **方針**: 絶縁IC+絶縁DC-DCで、PC側と下流側のD+/D-、VBUS、GNDを電気的に分離する。USB 2.0 Full Speed (12Mbps) までを対象にして、部品点数と費用を抑える

## 2. スコープ

対象はUSB 2.0 Full Speed (12Mbps) までの1ポート絶縁ハブ。High SpeedとUSB 3.x、PDは対象外とする。

| 項目 | 対象 | 対象外 |
| --- | --- | --- |
| 速度 | Full Speed (12Mbps) 固定 | Low Speed (1.5Mbps)、High Speed (480Mbps)、USB 3.x |
| 電源 | PC側USB-Cから5V(CC抵抗のみ) | USB-PD、急速充電 |
| 絶縁 | D+/D-、VBUS、GNDの分離(目的は下流短絡からのPC保護) | 高電圧機器との接続、医療・安全規格(認証)への適合 |
| ポート数 | 下流1ポート | ハブICによるポート増設、複数ポートの個別絶縁 |
| 製造 | tscircuitで設計し、JLCPCBで基板製造とSMD実装(PCBA)まで発注 | 量産、外装設計 |

## 3. 前提と未確定事項

**決定済み**

- [x] 通信速度: Full Speed 固定(SPU/SPD を FS 側に固定。Low Speed 機器は対象外)
- [x] 下流への供給電流: 最大200mA(1W級絶縁DC-DC)
- [x] 下流側の端子: USB-A(メス)
- [x] 絶縁の目的: 下流の短絡からPCを守ること。GND電位差対策や高電圧機器との接続は目的に含めない
- [x] ポート数: 下流1ポート(ハブICによる増設は初版に入れない)
- [x] 製造: JLCPCBで基板製造とSMD実装まで頼む。部品はLCSC在庫から選び、在庫がないものだけ手はんだ
- [x] 過電流保護: 電流制限付きロードスイッチ(ポリヒューズは使わない)
- [x] 下流VBUS: 出力が安定化された1W級絶縁DC-DCを使う
- [x] LED: 電源LED(PC側・下流側に1個ずつ)と、ロードスイッチの過電流フラグで点くエラーLED

## 4. 機能要件

| ID | 要件 | 優先度 |
| --- | --- | --- |
| F-01 | PC側USB-Cに接続すると5Vが供給され、デバイスとして認識される(CC1/CC2に5.1kΩをGNDへ) | 必須 |
| F-02 | PC側と下流側のD+/D-、VBUS、GNDを電気的に分離する | 必須 |
| F-03 | 下流のUSBデバイスがFull Speedで列挙・通信できる | 必須 |
| F-04 | 下流側の電源は絶縁DC-DCから供給し、PCのVBUSから直接取らない | 必須 |
| F-05 | 下流で短絡が起きても、電源が落ちるだけでPC側に影響しない | 必須 |
| F-06 | 下流の過電流を電流制限付きロードスイッチで制限し、短絡を外すと自動で復帰する | 必須 |
| F-07 | 下流端子はUSB-A(メス) | 必須 |
| F-08 | 電源LEDをPC側と下流側に1個ずつ置き、下流が短絡すると下流側LEDが消える | 必須 |
| F-09 | ロードスイッチの過電流フラグでエラーLEDを点ける | 必須 |

## 5. 電気的・非機能要件

| ID | 項目 | 要件 |
| --- | --- | --- |
| N-01 | 絶縁耐圧 | 2.5kV rms(ADuM3160)。目的が短絡保護なので5kV級は不要 |
| N-02 | 下流供給電流 | 最大200mA(1W級DC-DC) |
| N-03 | 短絡時の挙動 | 下流を短絡してもPC側VBUSの電圧・電流に変化がないこと |
| N-04 | 沿面距離・空間距離 | 絶縁境界に使う耐圧に見合う距離を確保し、境界にスリットを切る |
| N-05 | 通信速度 | Full Speed 12Mbps(High Speedは非対応) |
| N-06 | 発熱 | 連続使用でDC-DCや保護部品が触れないほど熱くならないこと |
| N-07 | 電源投入時 | PCに接続した状態で下流の抜き差しをしても、PC側が切断されないこと |

## 6. 構成案と部品候補

PC側から下流側へ渡る導体は、絶縁ICの信号(D+/D-)と絶縁DC-DCの電力(VBUS)の2経路だけにする。

```
        PC側 (GND_HOST)            │ 絶縁境界 │           下流側 (GND_ISO)
                                   │          │
 USB-C ──VBUS──┬──────────────[ 絶縁DC-DC ]──────── 保護 ── VBUS_ISO ─┐
 (Rd 5.1k×2)   │                   │          │                       │
               └─ VDD1             │          │            VDD2 ──────┤
 D+/D- ─────────────────────[   ADuM3160   ]─────────── D+/D- ── USB-A
                                   │          │
```

| 部品 | 候補 | 役割 |
| --- | --- | --- |
| 絶縁IC | ADuM3160(2.5kV rms) | D+/D-を絶縁したままFSで通信する |
| 絶縁DC-DC | 出力安定化型の1W級 5V→5V(LCSC在庫から選定) | 下流用の5Vを絶縁して作る |
| CC抵抗(PC側) | 5.1kΩ ×2(CC1/CC2→GND) | PCから5Vを受ける |
| 保護部品(下流側) | 電流制限付きロードスイッチ(過電流フラグ出力付き) | 短絡時に電流を制限し、エラーLEDを点ける |
| LED | 電源LED ×2(PC側・下流側)、エラーLED ×1(下流側) | 状態を表示する |
| 下流コネクタ | USB-A(メス) | 下流機器を接続する |

評価用には、ADuM3160の評価基板か完成モジュール(1,000〜2,000円程度)にUSB-Cブレークアウトをつなぐのが最短。

## 7. 基板設計要件

絶縁境界をまたぐ銅箔や配線を作らないことが最重要で、境界には沿面距離を確保したスリットを設ける。

- 絶縁ICと絶縁DC-DCを境界にまたがせて配置し、境界を横切る導体はこの2つだけにする
- 境界の下は全層で銅箔・ベタ・ビアを抜き、基板にスリットを切る
- PC側GNDと下流側GNDは別ベタにし、名前も分ける(GND_HOST / GND_ISO)
- USB-Cコネクタのシェルは、PC側GNDにだけ接続する
- 下流のUSB-Aのシェルは、下流側GNDにだけ接続する
- D+/D-はそれぞれの側で差動ペアとして短く引き、長さをそろえる
- 下流側のVBUSに、ロードスイッチとバルクコンデンサを置く
- LEDは、それぞれの側の電源とGNDで点ける(境界をまたいで配線しない)
- 絶縁ICとDC-DCの電源ピンの近くに、デカップリングコンデンサを置く

## 8. 試験項目と受入基準

短絡試験は、必ず無負荷での動作確認と絶縁確認を終えてから行う。

| ID | 試験 | 手順 | 合格条件 |
| --- | --- | --- | --- |
| T-01 | 絶縁確認 | 電源を入れない状態で、PC側GNDと下流側GNDの間の抵抗をテスターで測る | 導通がない(開放) |
| T-02 | 無負荷での電源確認 | PCに接続し、下流VBUSの電圧を測る | 約5Vが出る |
| T-03 | 列挙・通信 | 下流にUSBメモリやマイコンを接続する | PCから認識され、読み書きや通信ができる |
| T-04 | 抜き差し | 通信中に下流の機器を抜き差しする | PC側が切断されず、再接続で復帰する |
| T-05 | 下流短絡 | 下流のVBUSとGNDを短絡する | 電流が制限されてエラーLEDが点き、下流側の電源LEDが消える。PC側のVBUSとポートに異常がない |
| T-06 | 短絡解除 | 短絡を外す | 自動で復帰し、エラーLEDが消える |
| T-07 | 発熱確認 | 想定の最大電流で30分通電する | 部品が過熱しない |

## 9. リスクと対策

| リスク | 影響 | 対策 |
| --- | --- | --- |
| 絶縁境界の設計ミス(境界をまたぐ銅箔やシェル接続) | 絶縁が効かず、PCを保護できない | T-01で導通を確認。スリットと沿面距離を設計時にレビュー |
| 絶縁DC-DCの電流不足 | 下流機器が起動しない、電圧が落ちる | 下流は200mAまでと仕様で決める。超える機器は対象外 |
| Full Speedの速度制限 | 高速機器が使えない | 対象外と明記。必要なら市販の高速絶縁品を検討 |
| 下流短絡の発熱 | 部品の焼損 | ロードスイッチで電流を制限。T-05・T-07で確認 |
| 絶縁ICの耐圧不足 | 高電圧側とつなぐ用途で破壊 | 高電圧機器との接続は対象外と明記 |
| ノイズ・EMC | 通信エラー | 絶縁IC近傍のデカップリングと、短い配線を守る |

## 10. 技術的な論点(要件詰めで解決する)

決まったら上の各章に反映して、この章から消す。

1. **ロードスイッチの電流制限値。** DC-DCの定格(約200mA)を超えない値にする必要がある。固定制限品は500mA以上が多いので、抵抗で制限値を決められる品か、低い固定値の品をLCSC在庫から探す
2. **部品のLCSC在庫。** ADuM3160、安定化型の絶縁DC-DC、ロードスイッチ、USB-C/USB-Aコネクタが、JLCPCBの実装対象(Basic/Extended)にあるかを確認する。ないものは手はんだにするか、同等品に置き換える
3. **ADuM3160の電源。** PC側(VBUS1)と下流側(VBUS2)の両方に5Vを入れて、内蔵LDOの3.3V出力を使う構成にする。PDENやSPU/SPDの固定方法は回路図で決める
