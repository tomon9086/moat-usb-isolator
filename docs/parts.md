### 選んだ理由と見送った候補

- **U1 ADuM3160**: ADuM4160(5kV)は`-RL`品で9.75ドル。目的が短絡保護なので2.5kVで足りる
- **PS1 IB0505LS-1WR3**: 出力が安定化された1W品のうち、在庫が一番多い。連続短絡に耐えて自動復帰する。B0505S系(非安定化)は要件で外した。SMD品のIB0505XT-1WR3は在庫が100個未満
- **U2 TPS2553**: 電流制限値を抵抗で75mA〜1.7Aの範囲に設定でき、過電流フラグ(FAULT)を出せる。SY6280AACは安いがフラグ出力がないので見送った。`-1`付きはラッチオフ品で、自動復帰しないので使わない
- **J2**: 表面実装のUSB-Aは在庫が少ない品しかなかった。THTのほうが抜き差しにも強い

## 回路定数

### ADuM3160(U1)

| ピン | 接続 |
| --- | --- |
| VBUS1 | PC側VBUS |
| VDD1 | 内蔵LDOの3.3V出力。VBUS1〜VDD1とVDD1〜GND1にバイパスコンデンサ |
| PDEN | VDD1(通常動作) |
| SPU | VDD1(Full Speed) |
| VBUS2 | 絶縁DC-DCの5V出力(VBUS_ISO) |
| VDD2 | 内蔵LDOの3.3V出力。バイパスコンデンサ |
| PIN | VDD2(電源投入ですぐ列挙させる) |
| SPD | VDD2(Full Speed。SPUと必ずそろえる) |
| UD+/UD-、DD+/DD- | それぞれ24Ω ±1%の直列抵抗(FSでは4本とも必要) |

- バイパスは0.1µF以上の低ESR品を、ピンから10mm以内に置く
- 消費電流はFS通信中で片側6mA(最大8mA)
- SOIC-16Wの沿面距離は7.7mm。基板の境界もこれに合わせる

### 絶縁DC-DC(PS1)

- 入力電圧範囲は4.75〜5.25V(±5%)。PCのVBUSが4.75Vを下回ると仕様外になる
- 定格の10%(20mA)以上の負荷が必要。ダミー負荷として1kΩ(1206)を2本並列で置く(約10mA)。残りはADuM3160の側2(約6mA)とLEDでまかなう
- 出力の容量負荷は最大100µF。DC-DCの出力に10µF、USB-AのVBUSに47µFを置き、合計を100µF以下に抑える
- 入力には4.7µFを置く
- データシートでは「热插拔不支持」(ホットプラグ非対応)となっている。USB-Cの抜き差しで入力が跳ねないよう、PC側VBUSにTVS(D1)と入力コンデンサを置く
- ピン配置はSIP-4の標準配置と思われるが、データシートの図で回路図を描く前に確認する

### ロードスイッチ(U2)

電流制限値の式(データシートの式1):

- IOS(max) = 22980 / R^0.94
- IOS(nom) = 23950 / R^0.977
- IOS(min) = 25230 / R^1.016

(Rの単位はkΩ、電流はmA)

| RILIM | 最小 | 標準 | 最大 |
| --- | --- | --- | --- |
| 150kΩ | 155mA | 179mA | 207mA |
| **160kΩ(採用)** | **145mA** | **168mA** | **195mA** |
| 180kΩ | 129mA | 150mA | 174mA |

DC-DCの200mAから、ダミー負荷・ADuM3160・LEDの約20mAを引いた残りが下流に使える電流になる。最大値が180mA付近に収まる160kΩを選んだ。

- EN: VBUS_ISOにつないで常時オン
- FAULT: オープンドレイン。VBUS_ISOから赤LEDと抵抗を通してFAULTにつなぐと、過電流のときに点灯する(シンク電流は10mAまで)
- FAULTは過電流のとき7.5ms(typ)遅れて出る。コンデンサへの突入電流では点かない
